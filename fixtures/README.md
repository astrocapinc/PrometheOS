# Synthetic research fixtures

These small files are invented examples inspired by the *shape* of the KERS workflow. They are not results from the original project, validation of a controller, or claims suitable for a paper. The different operating regimes deliberately prevent an overbroad performance conclusion.

Acceptance tests ingest these files as real bytes, compute digests, create scoped claims, enter the meeting later than it occurred, apply a correction and inspect manuscript impact. Tests generate hostile files, long-context padding, audio stubs and disposable stores in temporary directories. Live audio/MATLAB/host/researcher gates cannot use these fixtures as proof.
