# Third-party notices

Generated by `tools/third_party_notices.py` from the dependency register; do not edit by hand. PrometheOS itself is under the Apache License 2.0 ([LICENSE](LICENSE), [NOTICE](NOTICE)). Licence fields are the components' own declarations, recorded when each was adopted; they are not legal advice. The release inventory ([docs/release/inventory.md](docs/release/inventory.md)) discusses compatibility and open items.

## What each artifact ships

- **The Python wheel** (`prometheos-*.whl`) bundles the hub's web assets, built from the packages in section 1, whose licence texts are at the end of this file. Its Python dependencies (section 2) are installed separately by the installer you use, each with its own licence files.
- **The Windows desktop installer** ships sections 1 to 4: the hub assets, CPython with the runtime dependencies and the MATLAB parsers, Electron and the NSIS installer stubs. Its full licence texts are in `resources/THIRD-PARTY-NOTICES.txt`, with Electron's and Chromium's next to `PrometheOS.exe`.
- **The agent packages** that `prometheos host setup` writes contain only PrometheOS's own files (Apache-2.0).
